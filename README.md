# Hive Breaker

Arcade Idle con defensa nocturna para Android. Cargas mineral con tus manos, lo fundes, lo
vendes a la flota y con cada crédito desbloqueas máquinas, torretas y drones que acaban
trabajando por ti. Pero cada máquina hace ruido, y el ruido despierta al enjambre.

- **El diseño:** [`docs/HIVE_Funcional.md`](docs/HIVE_Funcional.md) — fuente única de verdad.
- **Dónde estamos:** [`docs/ESTADO.md`](docs/ESTADO.md).
- **Cómo se trabaja aquí:** [`CLAUDE.md`](CLAUDE.md).

Para jugar en el ordenador: `node tools/build.js` y abrir `dist/hive_breaker.html`.

Dos reglas que valen para cualquiera que trabaje en este repositorio, desde el ordenador o
desde el móvil: **todo va a `main`, sin ramas**, y **cada sesión empieza trayendo (`git pull`)
y termina subiendo (`git push`)**.
